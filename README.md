# Vistoria Cautelar — CBS Fase III

App de celular (PWA) para vistoria cautelar dos imóveis vizinhos à obra da
Av. Bernardo Sayão — PROMABEN Fase III, Belém/PA.

- Funciona **sem internet** depois de aberto uma vez.
- Os dados ficam **só no aparelho** (nada vai para servidor).

## Testar no computador
```
python -m http.server 8000
```
Abrir http://localhost:8000 no Chrome.

## Publicar
GitHub Pages: Settings → Pages → Branch `main`, pasta `/ (root)`.
